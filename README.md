# 户型装修设计

> **自定义户型草稿**：此分支中的 `index.html` 已根据上传的住宅原始平面图，替换为主卧、次卧、未标注房间、双卫、厨房、客餐厅、阳台和玄关的 2D/3D 初稿。可见标注尺寸使用毫米；门窗、局部凹凸边界、层高，以及墙体的结构性质尚待现场和正式建筑图确认。
>
> **承重墙参考**：另收到一张同标准户型的承重墙示意照片，旋转匹配后，将其中 5 段位置较明确的深色加厚墙体标记为 `p`（疑似承重；开启“结构参考”图层时显示橙色）；其余结构属性未确认的室内墙仍标为 `u`（未知）。这两类墙在拆改工具中都禁止拆除。照片上的房号与原始平面图不同，且有摄影透视误差，**不能把本模型当作拆改许可或施工图，最终以本户正式结构图和专业核验为准。**

> **飘窗与门洞（V3 修订）**：按原始平面图补回 5 处飘窗：左侧主卫、次卧、客卫，以及右侧主卧、最下面的房间。飘窗使用独立的 `counted:false` 区域和 3D 台面，暂按 450 mm 台面高度建模；实际窗台高度、窗洞和异形细节仍需复核。底部房间门已移至房间上边墙的最左端，朝房间内部开启。

首次打开此分支时家具列表为空，方便按自己家的实际布置设计；浏览器数据使用独立的存储键 `huxing-huafa-9-1601-v1`，不会读取上游示例的家具方案。3D 层高暂按 2.8 米做视觉预览。房间面积是简化轮廓估算值，不可直接用于工程量结算。

纯前端的户型装修设计工具：在 2D 平面图上摆放家具、拆改墙体、测量尺寸，一键切换到 Three.js 3D 场景，可以鸟瞰，也可以第一人称漫游。整个应用就是一个 `index.html`，无需构建，打开即用。

## 功能

**2D 平面布置**
- 按原始户型 1:60 / 1:100 比例显示，尺寸单位 mm
- 从左侧家具库拖入 60 余种家具家电（卧室、客厅、餐厨、卫浴、家电、书房休闲）
- 拖动移动、旋转（Shift 自由角度）、调整尺寸，贴墙自动吸附
- 测量工具（靠近墙面自动吸附，Shift 锁定水平 / 垂直）
- 拆改非承重墙，承重墙单独标示
- 图层开关：尺寸标注、房间名、家具、网格、承重墙

**3D 场景**
- 鸟瞰、斜视、俯视多种视角，点击房间列表可飞到对应房间
- 漫游模式：桌面端 WASD + 鼠标，触屏设备用虚拟摇杆，可以点门开关
- 全高墙 / 剖切墙切换，日照时间滑块，夜景灯光
- 精细家具模型：柜门分缝与拉手、软包床头、带环境反射的金属与陶瓷材质等
- 在 3D 中也能选中、拖动家具，与 2D 方案实时同步

**方案与统计**
- 房间面积与套内使用面积自动统计
- 为每个房间更换地面材料（木地板、地砖、大理石、水磨石、地毯等），按面积加 5% 损耗估算造价
- 撤销 / 重做，方案自动保存在浏览器本地
- 中文 / English 界面切换（顶栏右侧按钮，默认中文，选择会记住）
- 导出 PNG 图片，导出 / 导入方案 JSON

## 快速开始

```bash
git clone <仓库地址>
cd <仓库目录>
```

然后直接用浏览器打开 `index.html`。也可以起一个本地静态服务器：

```bash
python3 -m http.server 8000
# 访问 http://localhost:8000
```

> Three.js 通过 jsDelivr CDN 加载，首次打开 3D 场景需要联网。

| 按键 | 作用 |
| --- | --- |
| `T` | 切换 2D / 3D |

| 漫游：`WASD` / 方向键，`Shift`，`E` | 移动，快走，开关门 |

## 技术栈

- 原生 HTML / CSS / JavaScript，无框架、无构建步骤
- 2D 平面图用 SVG 绘制
- 3D 场景用 [Three.js](https://threejs.org/) r160（OrbitControls、PointerLockControls、RoundedBoxGeometry、RoomEnvironment、CSS2DRenderer）
- 数据保存在 `localStorage`

## 自定义户型

户型数据写在 `index.html` 里：

- `ROOMS`：房间多边形、名称、默认地面材料
- `WALLS` / `WINS`：墙体与窗洞
- `MATS`：地面材料名称与单价
- `LIB`：家具库（类型、名称、默认尺寸、颜色）
- `buildFurniture()`：各类家具的 3D 模型

改这些数据就能换成自己的户型。
